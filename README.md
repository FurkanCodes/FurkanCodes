## Apps

**[Leaf Native](https://github.com/FurkanCodes/LeafNative)**  
A reader for books and papers on the Mac, built with SwiftUI and AppKit. Highlights and notes stay on your machine and export to Markdown and BibTeX.

**[Detour](https://github.com/FurkanCodes/detour)**  
Gets sites your ISP blocks loading again, in one click. It changes how the first packets of a connection look, so there is no VPN, no server and no account. Rust, for Windows and macOS.

**[Lamphaus](https://github.com/FurkanCodes/lamphaus)**  
One Android app with separate phone and TV interfaces, so what you were watching follows you from one screen to the other. Kotlin, Compose and Media3.

## Path of Exile 2
